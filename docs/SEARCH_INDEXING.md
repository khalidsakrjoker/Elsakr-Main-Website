# Search indexing checklist

Use after each SEO release. Record results only in local `plans/` (gitignored).

## Submit

1. Google Search Console → Sitemaps → submit `https://elsakr.company/sitemap.xml`
2. Bing Webmaster Tools → submit the same sitemap
3. Request indexing for: `/`, `/ar`, `/services`, `/ar/services`, `/about`, `/ar/about`
4. After content releases, also request: `/case-studies`, `/insights`, `/faq`, and their `/ar` mirrors

## Review weekly

- Indexed EN vs AR URL count
- Impressions / clicks / top queries
- Crawl errors and duplicate canonical warnings
- Core Web Vitals (field data in Search Console — not fabricated backend metrics)

## Local discovery files

- `https://elsakr.company/robots.txt`
- `https://elsakr.company/llms.txt`
- `https://elsakr.company/insights.xml`
